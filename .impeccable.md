# Impeccable — Design Configuration

This file persists design context for SoftSentry across all AI sessions.
Read the `## Design Context` section before doing any frontend/design work.

## Design Context

### Users

**Primary:** Corporate IT administrators and security operations staff who monitor
endpoint security posture across a fleet of Windows/macOS machines. They sit in
front of this console for long, continuous sessions — often triaging at odd hours.

**Context of use:** Long-dwell monitoring on large desktop displays (sometimes a
NOC/SOC wall). Data-dense work: scanning tables of machines, software inventory,
code-signing signatures, CVEs, licenses, policy whitelist/blacklist, alerts, and
audit logs. Decisions are consequential ("is this endpoint safe?"), so the
interface must never add drama or ambiguity of its own.

**Jobs to be done:**
- Spot risk fast — what changed, what's unsafe, what needs attention now.
- Triage with confidence at 2am without misreading a status.
- Drill from fleet overview → a single machine → a single piece of software.
- Trust the data: provenance, signature verdicts, and CVE matches must read as authoritative.

**Constraints:** Next.js 14 (App Router) + TypeScript + Tailwind + shadcn/ui +
Recharts. Tri-lingual (Thai / English / Japanese) — typography must handle Thai
ascenders/tone-marks and CJK glyphs gracefully. Role-based navigation (dev /
admin / viewer). Both light and dark themes are first-class.

### Brand Personality

**Three words:** Precise · Dependable · Quiet.

**Voice & tone:** Institutional and calm — a professional security tool you trust
at 2am. It states facts, never shouts. Confidence comes from clarity and
restraint, not from decoration. Think air-traffic-control display, not consumer SaaS.

**Emotional goal:** Calm authority. The admin should feel *in control and
informed*, never overwhelmed. The interface stays neutral so the data can speak;
the only thing that "raises its voice" is genuine risk.

### Aesthetic Direction

**Tone:** Calm-authority SOC console. Refined, utilitarian, information-dense but
never cluttered. Reference vibe: **Linear's precision meets a NOC/SOC wall.**

**The core idea — "Color is signal, not decoration":**
The canvas is a quiet, cool-tinted neutral. Saturated color is reserved almost
entirely for **risk semantics**, so the eye is trained to treat color as meaning:
- 🟢 **Safe / verified** — calm green
- 🟡 **Warning / needs review** — amber
- 🔴 **Critical / unsafe** — red
- ⚪ **Unknown / unscanned** — neutral grey (deliberately colorless)

**Signature / brand accent:** A cool, desaturated **iris-indigo** (distinct from
the stock shadcn 221° blue, and intentionally *not* any of the risk hues). Used
sparingly and flat — active nav, focus rings, primary actions, links, selection —
never as a glow or a gradient. It signals "the product," not "a status."

**Neutrals:** Tinted slightly cool toward the iris hue (not pure grey, never pure
black/white) so the whole surface feels cohesive and engineered.

**Theme:** True dual light/dark. Dark is a deep desaturated blue-charcoal (a real
SOC night surface, not pure black with neon). Light is a soft cool off-white (not
#fff). Risk colors are tuned per-theme to keep equal legibility and contrast.

**Anti-references (what this must NOT look like):**
- Stock shadcn/ui blue-on-slate template (the current baseline — escape it).
- "AI slop": cyan-on-dark, purple→blue gradients, neon glows on dark, glassmorphism,
  gradient text on metrics, identical icon-topped card grids, everything-in-a-card.
- Consumer/playful SaaS. No bounce/elastic motion, no rounded toy aesthetics.
- Monospace used as lazy "technical" shorthand (mono is allowed ONLY for genuine
  machine data: hashes, IDs, versions, certificate thumbprints).

### Design Principles

1. **Color = risk signal.** Keep the canvas neutral; spend saturation only on
   meaning. If everything is colored, nothing reads as urgent.
2. **Density with rhythm.** This is a data tool — embrace tables and information
   density, but create breathing room through deliberate spacing rhythm and clear
   typographic hierarchy, not by hiding data.
3. **Legible at a glance, trustworthy on inspection.** Status must be unmistakable
   from across a room; detail must be exact and unembellished up close.
4. **Restraint over flourish.** Every decorative element must justify itself.
   Motion conveys state change only (entrances, updates), with smooth ease-out —
   never bounce, never decoration.
5. **Tri-lingual & dual-theme by construction.** Choose type and tokens that hold
   up in Thai, English, and Japanese, and across light and dark, from the start —
   not as an afterthought.
